## Imagery

## Iconography

UI icons (navigation, form controls, social links, dashboard) are
hand-drawn inline SVG following the [Feather Icons](https://feathericons.com/)
visual style (MIT License) — redrawn directly in markup rather than imported
as a dependency, so there is no icon-font or sprite-sheet build step.
